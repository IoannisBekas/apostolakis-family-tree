# Οικογένεια Αποστολάκη

Στατικό, διαδραστικό γενεαλογικό δέντρο βασισμένο στο διαθέσιμο οικογενειακό αρχείο.

## Λειτουργίες

- Αναζήτηση προσώπου και αυτόματο άνοιγμα ολόκληρης της καταγωγικής διαδρομής
- Προβολές δένδρου, προγόνων και απογόνων
- Κάρτα προσώπου με σύζυγο, παιδιά, τόπους και απόσπασμα του αρχείου
- Φίλτρο τόπου και εναλλαγή εμφάνισης συζύγων
- Έλεγχος συγγένειας δύο προσώπων με επισήμανση του κοινού προγόνου
- Ζουμ, εστίαση, προσαρμογή προβολής και πλοήγηση ανά γάμο
- Κοινόχρηστος σύνδεσμος που διατηρεί τον ανοιχτό κλάδο και την επιλογή
- Εξαγωγή PNG και εκτύπωση / αποθήκευση ως PDF

## Τοπική προβολή

Από τον φάκελο του project:

```powershell
python -m http.server 4173
```

Άνοιξε έπειτα το `http://127.0.0.1:4173/`.

## Δεδομένα

Τα δεδομένα βρίσκονται στο `assets/family_units.json`. Οι σχέσεις και τα ονόματα παρουσιάζονται όπως καταγράφονται στο αρχικό οικογενειακό αρχείο· όπου απουσιάζει πληροφορία συζύγου, αυτό σημειώνεται ρητά στην εφαρμογή.
